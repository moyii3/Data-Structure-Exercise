# 项目介绍

</div>

本项目是我个人暑假期间做的数据结构相关代码练习，集成了不同模块的相关代码测试菜单，方便测试。

## 一、相关代码练习

### 1. 顺序表
- 顺序表的初始化、销毁、求长度
- 结点的查找、添加、删除

### 2. 单链表
- 链表的初始化、销毁、清空、求长度、判空、头插法与尾插法建立、反转
- 结点的数据显示、查找（通过位置或值）、插入、删除

### 3. 双链表
- 双链表的建立、显示、有序递归合并、有序迭代合并、倒序输出
- 结点的查找、插入、删除

### 4. 二叉树
- 二叉树的先根建立、先序遍历、迭代中序遍历、层序遍历（简易队列版）、双栈后序遍历

### 5. 其他
- 主菜单函数：含顺序表，单双链表，二叉树代码测试菜单函数
- 栈：初始化，入栈，出栈，判空

# 个人感悟

</div>

这个暑假算是做出了一些改变，虽然好像练习的并不多，但至少迈出了一步，没有虚度整个暑假。

其中最大的收获应该是进一步理解了递归算法，并且由此明白了栈是什么，与堆的区别就在于，前者存储连续，空间利用率高，
且遵循后进先出的数据存储形式，但栈的空间相对较小，如果递归深度过深，会造成栈溢出，可以用尾递归的方式尽量减轻栈内存
的占用，或者用迭代的手动栈在内存更大一点的堆区运行。当然这些只是我目前粗浅的认知，也许有些不对，但至少有了一定了解，
只要不断去学就好了！
